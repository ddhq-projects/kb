## Что это

Раздел с **шаблонами дашбордов для команды топ-руководителей** — ролевая модель data driven управления. Для каждой C-level роли: список метрик, формулы расчёта, референсные значения (Min/Max), форматы визуализации, примеры алертов и бизнес-контекст.

Источник — материал Cloud.ru про Evolution Data Platform, но шаблоны метрик универсальны и применимы к любой BI-системе.

## Почему data driven — не тренд, а выживание

- Компании с культурой работы с данными генерируют на **15–20% больше EBITDA** (McKinsey & BCG)
- Организации на данных реагируют на изменения рынка **в 3 раза быстрее** (HBR)
- **68% руководителей** не доверяют данным в своей организации (Gartner)
- К 2025 году компании без практик управления данными теряют **30% конкурентоспособности** (Forrester)

> Побеждает не тот, у кого больше данных (Big Data), а тот, кто быстрее превращает их в решения (Smart Data).

## Структура каждого дашборда

Каждая страница раздела содержит:

1. **Метрики** — таблица с формулой, частотой обновления, референсом (Min/Max) и форматом визуализации
2. **Алерты** — пороговые значения для уведомлений
3. **Бизнес-контекст** — зачем метрика для бизнеса, когда полезна
