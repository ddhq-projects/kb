## Что такое BI-дашборды

**BI-дашборд** (панель показателей) — интерактивный инструмент визуализации, который собирает ключевые метрики компании из разных источников (CRM, ERP, базы данных, файлы) и представляет их в виде графиков, диаграмм и таблиц для принятия управленческих решений.

### Типовая архитектура BI-решения

1. **Источники данных** — OLTP-базы, CRM/ERP, файлы (CSV, Excel), API.
2. **ETL/ELT** — извлечение, преобразование и загрузка данных.
3. **Хранилище данных (DWH)** — централизованная база, оптимизированная для аналитики.
4. **OLAP-сервер** — многомерное представление для быстрых агрегаций.
5. **Слой визуализации** — дашборды с виджетами, фильтрами и drill-down.

### Модели развёртывания

- **SaaS (облачные)** — не требуют собственной инфраструктуры, быстрое внедрение, оплата по подписке.
- **On-premise (локальные)** — полный контроль над данными, соответствие регуляторным требованиям (ФСТЭК), выше стоимость владения.

### Основные сценарии

- **Продажи и маркетинг** — воронки, KPI, динамика выручки, конверсии.
- **HR-аналитика** — текучесть кадров, эффективность найма, загрузка персонала.
- **Финансовая отчётность** — P&L, движение денежных средств, бюджетный контроль.
- **Операционные метрики** — логистика, производство, качество обслуживания.

## Детальный обзор платформ

### Яндекс DataLens

Облачная BI-платформа от Яндекса, лидер рейтинга CNewsMarket 2026 (1 345 баллов). Входит в экосистему Yandex Cloud.

**Сильные стороны:**
- Минимальный порог входа — бесплатно для одного пользователя, доп. рабочие места по 990 ₽/мес.
- Встроенный ИИ-помощник «Нейроаналитик» для генерации визуализаций по текстовому запросу.
- Поддержка множества коннекторов: ClickHouse, PostgreSQL, MS SQL, MySQL, API, CSV, Excel.
- Интеграция с сервисами Яндекса (Метрика, Директ и др.) — максимальный эффект при использовании всей экосистемы.
- Быстрый запуск без сложного внедрения, интуитивный интерфейс.

**Слабые стороны:**
- Нет собственного хранилища данных — все запросы выполняются напрямую к внешним источникам в режиме live, что создаёт нагрузку на продуктивные базы.
- Отсутствие встроенного ETL — подготовку данных нужно выполнять отдельными инструментами.
- При больших объёмах требуется оптимизация запросов.
- Максимальные возможности раскрываются только в связке с другими сервисами Яндекса.

### Apache Superset

Полностью открытая BI-платформа (лицензия Apache 2.0), разрабатываемая при поддержке компании Preset. Активно используется в России как бесплатная альтернатива коммерческим BI.

**Сильные стороны:**
- Бесплатный исходный код без скрытых коммерческих модулей, возможность свободной модификации и развёртывания на своих серверах.
- Очень активное сообщество: в декабре 2025 года принято 266 pull request'ов от 42 контрибьюторов.
- Подключение практически к любым СУБД через драйверы SQLAlchemy (PostgreSQL, MySQL, ClickHouse, BigQuery и др.).
- Интерактивные дашборды «из коробки» с фильтрами, алертами, возможностью шаринга.
- Покрывает 80–90% задач, решаемых Power BI и Tableau.

**Слабые стороны:**
- Требует технической экспертизы и знания SQL — несмотря на улучшение no-code интерфейсов, платформа рассчитана на пользователей, знакомых с языком запросов.
- Необходимость самостоятельного развёртывания и администрирования: серверная инфраструктура, настройка безопасности, бэкапы.
- В РФ есть интеграторы (например, Techpeople): пилот от 95 000 ₽, комплексный проект от 500 000 ₽.

### Bitrix24 BI-конструктор

Модуль бизнес-аналитики, встроенный в экосистему Bitrix24. Основан на Apache Superset, но представляет собой адаптированную и ограниченную версию.

**Сильные стороны:**
- Доступен «из коробки» в составе подписки Bitrix24 (начиная с тарифа «Стандарт»), не требует дополнительных лицензий на BI.
- Работает внутри инфраструктуры Bitrix24 — данные не передаются третьим лицам.
- Готовые датасеты по сделкам, лидам, контактам, звонкам — аналитика без кода для пользователей CRM.
- Быстрый старт: простой дашборд можно собрать за несколько минут без привлечения разработчиков.

**Слабые стороны:**
- Встроенная версия Superset урезана по функционалу: меньше возможностей настройки, слабая кастомизация, ограничения в доработках на React.
- Слабая работа с внешними источниками (1С, рекламные системы, внешние БД) — инструмент ориентирован на данные внутри Битрикс24.
- Ограничения производительности при росте объёмов данных: отчёты считаются дольше, требуются ручные ограничения выборок.
- Нет полноценного ETL и слоя подготовки данных — сложные сценарии с несколькими источниками реализуются с трудом.

### PIX BI (PIX Robotics)

Self-service BI-платформа со встроенным модулем ETL, AI-ассистентом для генерации визуализаций и инструментом «PIX Переходник» для автоматического анализа и миграции с Power BI. Входит в реестр отечественного ПО (№15808).

- **BASE** (просмотр дашбордов) — 25 000 ₽/год.
- **PRO** (создание дашбордов) — 50 000 ₽/год за пользователя.

### Luxms BI

Промышленная BI-платформа с фокусом на безопасность: сертификация ФСТЭК по 4 уровню доверия (апрель 2026), датацентричная двухзвенная архитектура на PostgreSQL, собственная разработка без зависимости от иностранных библиотек. Поддерживает российские ОС (Astra Linux, РЕД ОС, Альт СП). Стоимость — от 14 400 ₽/год за пользователя.

### Модус BI (ООО «БиАй Про»)

Российский вендор, предлагающий BI и ETL в едином решении. Ключевая особенность — нативная интеграция с 1С (специализированный адаптер ETL-1С, работа с запросами на языке 1С). Поддерживает адаптивную вёрстку для мобильных устройств. Бессрочные лицензии — от ~800 000 ₽, годовые подписки — по запросу.

### Сбер Навигатор BI

BI-платформа от Сбера с ИИ-аналитиком, способным обрабатывать документы и находить ответы. Поддерживает коннекторы к PostgreSQL, ClickHouse, MS SQL, MySQL, Oracle. Имеет готовые отраслевые решения (банки, застройщики, гостиничный бизнес). Стоимость предоставляется по запросу.

### Cloud.ru Evolution Managed BI

Управляемый сервис визуализации данных по SQL-запросам в составе платформы Cloud.ru Evolution Data Platform. Дашборды, отчёты, права доступа, экспорт. Раскрывается в связке с другими сервисами платформы:

| Сервис Evolution | Назначение |
|------------------|-----------|
| **Managed Trino** | MPP SQL-движок для аналитики больших данных, JOIN между источниками |
| **Managed Spark** | Распределённая обработка, GPU для ML-задач |
| **Managed Metastore** | Управление метаданными таблиц, External Tables в Object Storage |
| **Arenadata DB** | Корпоративное хранилище данных до 50 ТБ, MPP-архитектура |
| **Managed Airflow** | Оркестрация пайплайнов, DAG-и для ETL |
| **Managed Flink** | Потоковая обработка в реальном времени, Kafka-источники |

Платформа объединяет **данные, приложения и искусственный интеллект** в единую среду для быстрого запуска цифровых решений — подходит для компаний, которым нужна комплексная data-платформа, а не только слой визуализации.

## Тренды 2025–2026

- **Импортозамещение** зарубежных инструментов (Power BI, Tableau, Qlik) российскими решениями.
- **ИИ-ассистенты** в BI: Нейроаналитик в DataLens, AI в PIX BI, ИИ-аналитик в Сбер Навигатор.
- **Self-service аналитика** для бизнес-пользователей без навыков программирования.
- **Open-source** как альтернатива коммерческим решениям — Apache Superset набирает популярность.
